# Itsycal-4-WB

这是 [Itsycal](https://github.com/sfsam/Itsycal) 的个人 fork，目的是让 macOS 菜单栏日历更简洁，并方便查看中国农历。

- 移除底部日程列表和工具栏，将固定、设置按钮放到顶部。
- 保持日历宽度，增加农历日期、闰月和常见传统节日标注。
- 收紧底部留白，保留月份边框、周末高亮和日历事件圆点。

农历展示方式参考 [LunarBar](https://github.com/LunarBar-app/LunarBar)，转换使用 macOS 自带日历能力。

安装包见 [Releases](https://github.com/DexterW97/Itsycal-4-WB/releases)。当前版本要求 macOS 27 或更高版本；本地构建方式见 [BUILD.md](BUILD.md)。项目沿用上游的 [MIT 许可证](LICENSE.txt)。
